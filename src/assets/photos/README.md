# 写真台帳と差し替え手順

実装・画像サイズ確認：2026-09-07。[文章・素材の運用](../../../docs/content-and-assets.md)。

ここにはサイト用の原本を置く。Astro Imageがビルド時にリサイズ・WebP化・複数解像度を生成する。`dist/` の画像を直接編集しない。同名で差し替えれば参照は保てるが、切り抜き・表示サイズ・配布用コピーは別途確認する。

2026-09-13にトップのヒーローを `hero-panel.jpg` へ差し替えた。表情が明るいという本人の希望による。縦長では横長写真が拡大されて顔が寄りすぎるため、`.hero-actor` の高さを親の `75%` に抑えて縮小率を下げ、上半身と会場が入る引きの画にした。`.hero` は `min-height` なので内容によって実際の高さが伸びる。`svh` など画面基準の単位で指定すると画像だけがヒーロー本体とズレるため、必ず割合で持たせる。あわせて縦画面では `object-position:0 0`、スポットの中心（`.hero-actor` と `.spot-dust` のマスク）を64%前後に置いている。左揃えの見出しに顔が重ならないよう、人物を画面の右寄りに出すための組み合わせで、実機の390pxで確認した。**写真を替えると人物の位置が変わるので、`object-position` とマスクの中心は必ずセットで見直すこと。****OGPの元写真は `speaking-closeup.jpg` のまま**で、ヒーローとは別の写真になっている。そろえる場合は[OGP手順](../../../scripts/ogp/README.md)で再生成する。

`hero-panel.jpg` は他の登壇者が写り込んでいるが、ヒーローのマスクで表示範囲外になる。**本人の周囲だけを切り抜いて使う案を試したが、縦画面ではマスクの中心から顔が外れて破綻したため、元の画角のまま使っている。**マスクが実質的な切り抜きとして働くので、画像側で切る必要はない。プレス配布には使わない。

`speaking-mic.jpg` は依頼ページ冒頭に置いた。依頼を検討する人が知りたい「人前でどう話すか」を、文章の前に見せるため。他の人は写っていない。

「参照なし」はAstroのページ・コンポーネントのimportを確認した結果。CMSの画像は別管理なので、ファイル名だけから記事での使用を断定しない。旧文書にあったトップ全幅の青背景写真の帯は、現在の構成にはない。

## 差し替え

1. 原本を保管し、使用する写真と許諾・用途を確認する。
2. 同名で差し替えるか、参照元を含めて変更する。`rg 'assets/photos' src` で使用先を確認する。
3. PC・390px・必要に応じ320pxで、顔や頭の切れ、周囲の文字、画像の拡大アニメーションを確認する。
4. プレス配布対象なら `public/press/` のコピーと `src/pages/press.astro` の `photos`、`spec` の解像度表記も更新する。
5. ヒーロー写真を変更する場合は [OGP手順](../../../scripts/ogp/README.md)の元写真も確認する。OGPは自動では再生成されない。

## プレス配布の対応

| サイト用 | 配布用 |
|---|---|
| `portrait-front.jpg` | `public/press/ozaken-portrait-front.jpg` |
| `portrait.jpg` | `public/press/ozaken-portrait.jpg` |

プレスキットで配る写真はこの2枚。登壇写真は以前の本人の希望で配布対象から外している。新たに追加する場合は用途と希望を照合する。

正面写真は現時点で1334×2000。より高解像度の原本が得られた場合はサイト用・配布用・解像度表記の3つをそろえる。大きくしただけの画像を高解像度の撮影原本と説明しない。

## 文脈を確認する写真

`audience.jpg` は客席の顔を識別できる。主催者側の許諾条件を確認できるまで新たに実装で使わない。`genspark.jpg` はロゴが目立つため、実際のイベントが分かる記事等の文脈で使い、提携関係の演出にしない。
