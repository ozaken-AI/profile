# 写真

ここにある写真をサイトが使います。**ファイル名は実装から参照しているので、変えないでください。**
差し替えるときは、同じ名前で上書きしてください。

元データのまま置いてあります。リサイズ・圧縮・WebP変換・複数解像度の書き出しは
ビルド時に自動で行うので、手前で縮小する必要はありません。

## 使い方を変えた点

トップの全幅の帯は、当初 `hero-stage.jpg`（顔のアップ）でした。
16:7 に切ると顔だけが画面いっぱいに出て、「登壇の現場」ではなく
引き伸ばした証明写真のように見えたため、**`portrait-full.jpg`（全身・青背景）に変えました。**
立ち姿なので、頭が切れないよう `.stage--top` で切り出す位置を上に寄せています
（スクロールで上下に動くぶんの余裕も見込んだ値です）。


当初は数字セクションの背景に `audience.jpg` を予定していましたが、**`venue.jpg` に変えました。**

- `venue.jpg` は人物が小さく客席がシルエットなので、暗く敷いて数字を重ねるのに向いている
- `audience.jpg` は前列の顔が識別できるため、背景に敷くには扱いが重い

## 扱いに注意が必要な2枚

- **`audience.jpg`** … 客席の顔が識別できます。使う前に、撮影したイベントの主催者側の
  許諾条件を確認してください。確認が取れるまでは実装で参照しません。
- **`genspark.jpg`** … Genspark のロゴが大きく写っています。イベント写真として自然な範囲ですが、
  トップの主役に据えると提携関係と誤読される可能性があるため、文脈が付く場所
  （お知らせの記事内）に限って使います。

## あると使いどころが増えるもの

急ぎではありません。

- **執務・対話のカット** … 登壇以外の場面。アドバイザリーの説明に添えると説得力が出ます
- **横位置のポートレート** … いま縦（2:3）が1枚だけなので、横長の枠に収まりません
