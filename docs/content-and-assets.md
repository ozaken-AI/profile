# 文章・実績・SEO・素材の運用

最終確認：2026-09-07。[全体の手順](operations.md)／[決定事項](decisions.md)。

## 誰に何を伝えるか

主な依頼者は企業の経営層・企画担当者。AIの知識量だけでなく「自社の課題を理解し、経営と現場を前へ進めてくれそうか」を判断できる構成にする。

- トップは活動全体の入口。経営・助言、導入支援、講演・研修、執筆、協会活動を伝える。`For business leaders` を講演だけの説明に戻さない。
- 講演・研修・組織変革・顧問の比較は `/speaking/` の1ページで完結させる。[編集手順](speaking-page.md)を参照。「代表的な登壇」の紹介は2026-09-10の本人希望で詳細ページも含めて削除した。確認済みデータが残っていても、紹介枠を復活させない。
- お知らせは多様な登壇・活動を継続的に伝えるため、トップのヒーロー直後に最新8件を置く。
- 依頼ページは「誰の、どの課題に」「何を持ち帰れるか」「形式・進め方」「根拠」「相談への入口」の順で読めるようにする。実在しない導入成果・顧客の声・取引先ロゴを補わない。
- 費用は本人の希望で**個別見積もり**。推測の価格帯や交通費条件を追加しない。

## SEOの確認

1. 検索する人の目的と本文をそろえる。講演依頼ページで対象者・テーマ・進行・相談方法が分かるか確認する。
2. title / descriptionをページ固有にする。実績の年・集計範囲が本文と食い違わないようにする。
3. H1、見出し階層、内部リンク、画像のalt、canonicalを確認する。検索語を不自然に列挙しない。
4. `Base.astro` のPersonの識別子は `https://ozaken.ai/#person`。トップのWebSite、プロフィールのProfilePage、依頼ページのService、記事のArticleなど、ページに合う構造化データを保つ。
5. `sameAs`・所属・受賞・レビュー・料金を架空の情報で埋めない。画面にない内容をJSON-LDだけに足さない。
6. `npm run build` 後、該当HTMLと `sitemap-index.xml` を確認する。ニュースの取得上限・失敗時の挙動は[CMS設定](microcms-setup.md)を参照する。

アクセスの改善は[解析](analytics.md)で確認する。相談ボタンのクリック、送信成功、成約は別の指標で、クリックから受注までを自動で追えているわけではない。

## 写真・ロゴ・プレスキット

- 写真の原本と実際の使用場所は [写真台帳](../src/assets/photos/README.md)。`src/assets/photos/` をAstro Imageで変換する。生成された `dist/` を直接編集しない。
- 同名で差し替える場合もPC・スマートフォンの切り抜きを確認する。顔・頭・文字が枠外へ出ないようにする。
- `/press/` の顔写真は正面・斜めの2枚。サイト用原本、`public/press/` の配布用コピー、`src/pages/press.astro` の `photos` と解像度表記をそろえる。
- ロゴは既存の公式PNG・AIデータを使い、生成AIで描き直さない。白用・カラー用、マーク・フルロゴを混同しない。
- ロゴの対応は `press.astro` の `logos` 配列と `public/press/logos/`。現在の掲載はAICX協会のロゴ・マーク各2種（計4点）のPNGと、ベクター版の問い合わせ案内。AI Agent Day 2025の2点は2026-09-10の本人希望でページから削除済み。AIファイルがGit内にあることと、画面で配布している形式を区別する。
- プロフィール文の配布は `BIO` の画面内コピー。**現在、プロフィールTXTダウンロードは実装されていない。** 新規に追加するなら実ファイル・リンク・更新手順を同時に作る。
- 客席写真の人物や企業ロゴは元の許諾・イベントの文脈を確認する。写真にロゴが写っていることを、取引・提携の証明にしない。

告知用には `/press/` の本人情報・写真を使い、肩書き、主催者、開催日、参加条件、URLを依頼内容と照合する。SNS投稿・主催者へのメール送付は、素材作成と別の外部操作として依頼範囲を確認する。

## YouTubeへの導線（2026-09-10追加）

本人指定のチャンネルは [AI現場報告](https://www.youtube.com/@AI_Field_Report)。URLと名称は `SITE.youtube` / `SITE.youtubeName` に集約し、トップの「動画と資料」セクションと共通フッターから案内する。トップはYouTubeと講演・実践資料の2つのカードを並べ、760px以下では縦に並べる。

紹介文はチャンネルの公開説明・動画一覧で確認した、生成AIの使い方、企業での活用、対談・解説・現場レポートに基づく。登録者数・投稿本数・更新頻度は固定表示しない。番組チャンネルをPersonの `sameAs` に自動で追加しない。

動画プレーヤーの埋め込みや自動再生は行わず、チャンネルへ直接リンクする。外部クリックは既存の `outbound_click` の対象。URL変更時はカードとフッター、PC・モバイルの表示、リンク先、キーボードのフォーカスを確認する。

## ファビコン・サイトアイコン

`public/` の `favicon.svg`、`favicon.ico`、`favicon-32.png`、`favicon-96.png`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png` と `site.webmanifest` を確認する。参照元は `Base.astro` とmanifest。OGPとは別の画像・キャッシュで、`OG_VERSION` の変更だけではアイコンは更新されない。

差し替える場合は、元の肖像・デザインから各寸法を用意し、manifestのsizes、各linkのURLとバージョン表記、実画像の寸法をそろえる。小さいタブ表示とホーム画面用の表示を確認する。生成の専用スクリプトは現在このリポジトリにはないため、再作成した際は元データと再現手順を残す。キャッシュ期間は `public/_headers` を参照する。

## 2026-09-11のトップ構成

ヒーロー（3形式への短いリンク）→最新のお知らせ8件→目的別の3形式→集計条件付きの数字→短いプロフィールと役職→動画・コンテンツ一覧→相談。2026-09-11の本人の希望でトップの講演シリーズ予告を削除。重複評価により組織名だけの一覧も削除した。講演テーマや詳しい条件と流れは `/speaking/` 内へ直接リンクする。

heroのCTA・ナビ・title・descriptionは講演、研修、顧問・アドバイザーの3形式に合わせ、組織変革は顧問の支援内容として説明する。資料の入口は「コンテンツ一覧」として `content.ozaken.ai/` へ案内し、「一部を無料でご覧いただけます」と明記する。全コンテンツが無料・キー不要と読める紹介にはしない。

ニュース本文がある場合、excerptはメタ説明に使い、画面で本文の前に重ねて表示しない。記事末尾には依頼ページと相談先を設ける。カテゴリーや見出しから案内種別を選ぶが、新たな発言・成果・参加者の反応を生成しない。
