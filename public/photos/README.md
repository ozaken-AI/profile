# 写真の置き場

ここに写真を置くと、サイトが使います。**ファイル名は下の表のとおりにしてください。**
実装側がこの名前で参照するため、名前が違うと表示されません。

拡張子は `.jpg` を想定しています。`.jpeg` や `.png` の場合は、拡張子だけ合わせてもらえれば
こちらで実装側を合わせます。

## ファイル名と使いどころ

| ファイル名 | 写真 | 使う場所 | 必要な比率 |
|---|---|---|---|
| `hero-stage.jpg` | 黒スーツ・正面・笑顔（背景が真っ黒の1枚） | トップのヒーロー直後、画面幅いっぱいの帯 | 横長 16:9 以上 |
| `audience.jpg` | 後ろ姿と客席（東北のイベント） | 数字セクションの背景。暗く敷いて数字を重ねる | 横長 16:9 |
| `portrait.jpg` | スタジオポートレート（グレー背景） | プロフィール、プレスキットのメイン | 縦 3:4 |
| `portrait-full.jpg` | 全身・両手を広げた1枚（青背景） | プロフィール | 横長 16:9 |
| `speaking-standing.jpg` | 藍染の作務衣・全身（Updata NOW） | 講演メニュー「立って話す形式」 | 横長 16:10 |
| `speaking-seated.jpg` | 着席・マイク・手のジェスチャー | 講演メニュー「座って議論する形式」 | 横長 16:10 |
| `genspark.jpg` | Genspark ステージ・正面 | お知らせのサムネイル | 横長 16:9 |

比率はトリミングの目安です。**元データのまま置いてください。** リサイズ・圧縮・WebP変換・
複数解像度の書き出しは実装側で自動的に行います。手前で縮小すると画質が落ちるだけです。

## アップロードのしかた

パソコンから GitHub で完結します。

1. https://github.com/ozaken-AI/profile の `public/photos` を開く
2. 右上の **Add file** → **Upload files**
3. 写真をドラッグ＆ドロップ（複数まとめて可）
4. アップロード後、ファイル名が表の名前と違っていれば、各ファイルの
   鉛筆アイコン → **Rename** で直す
5. 下の **Commit changes** を押す

スマホからでもブラウザで同じ操作ができます。

## 撮影を追加するときの目安

いま足りていないのは次の2種類です。急ぎではありませんが、あると使いどころが増えます。

- **執務・対話のカット** … 登壇以外の場面。アドバイザリーの説明に添えると説得力が出ます
- **横位置のポートレート** … 縦position 3:4 だけだと、横長の枠に収まりません

## 権利まわりのメモ

- **客席が写っている写真** … 前列の顔が識別できるものは、主催者側の許諾条件を確認してから使ってください。
  数字セクションの背景は暗く敷くため実質わかりませんが、他の用途に転用するときは注意が必要です。
- **イベントのロゴが写っている写真** … Genspark、Updata NOW など。イベント写真として自然な範囲ですが、
  トップの主役に据えると提携関係と誤読される可能性があります。文脈が付く場所（お知らせ、実績）向きです。
