# OGP画像の再生成

実装確認：2026-09-07。[文章・素材の運用](../../docs/content-and-assets.md)。対象は `public/ogp.png` と `public/ogp-speaking.png`、いずれも1200×630。Astroのビルドで自動生成される画像ではない。

## まず文言をそろえる

元HTMLは [template.html](template.html)。**現在は登壇数の「回／年」など旧表記が残り、Udemyの集計時点も入っていない。** 今回の運用文書整備では画像を再生成していない。次の生成時には `src/lib/site.ts` と確定条件を照合し、テンプレートの文言を修正してから書き出す。

登壇300回超は2025年の本人集計、Udemy受講者5万人超は2026年8月時点。数値だけでなく期間・範囲を画像内でも読める形にする。顔写真・肩書き・依頼の説明も同時に照合する。

## 入力を用意する

テンプレートと同じディレクトリに、以下の参照ファイルが必要。これらはテンプレートの横にはコミットされていないため、クリーンなcloneでそのまま開いても同じ見た目にならない。

| 必要なファイル | 用意するもの |
|---|---|
| `hero.jpg` | `src/assets/photos/speaking-closeup.jpg` のコピー |
| `seal.png` | `public/favicon-96.png`、または確認済みの大きな正方形原本 |
| `fonts.css` と `fonts/` | Shippori Mincho B1 / Archivo / Zen Kaku Gothic Newのフォント定義と実ファイル |

リポジトリ外の一時ディレクトリにテンプレートと入力をまとめると、原本や生成中の補助ファイルを混ぜずに作業できる。ネットワークからフォントを読み込む場合はテンプレートのlinkを利用可能なフォントCSSへ変更し、全書体の読み込みが終わってから撮影する。準備したフォントの出所と版も再現に必要なら記録する。

テンプレートに必要な修正は `scripts/ogp/template.html` へ戻して残す。一時ディレクトリだけを修正して終えない。

## 撮影・確認

1. テンプレートをローカルで配信し、利用環境のブラウザ制御ルールに従って開く。
2. 1200×630の画面、拡大率100%で画像・フォントの読み込みを確認する。
3. 通常URLを `ogp.png`、`?v=speaking` を付けたURLを `ogp-speaking.png` としてPNGで書き出す。DPRによって倍寸になる場合は出力設定を見直し、実際のピクセル寸法を確認する。
4. 文字欠け、文字化け、写真の位置、余白、細い文字、塗りと輪郭の境界を実画像で確認する。縮小したSNSカード相当の大きさでも読む。
5. `public/` の2ファイルを差し替え、テンプレート・画像の差分を確認する。

見出しは塗りと輪郭の2枚重ね。CSS変数 `--cut` が写真との境界なので、見出しの切り分けと写真位置を一緒に調整する。画像だけずらすと境界がずれる。

## 配信とキャッシュ

`src/layouts/Base.astro` の `OG_VERSION`（確認時点は `3`）を、実際に画像を差し替えたときに更新する。メタタグが参照する画像URLと画像寸法をビルド後に確認し、通常のPR・本番デプロイを通す。

`public/_headers` のOGPキャッシュは1週間。SNS側にも独自のキャッシュがあるので、デプロイ直後の古いカードだけで失敗と決めつけない。必要なら対象SNSの再取得手段を使うが、即時反映を保証しない。

検証記録には元画像、テンプレート変更、出力サイズ、確認した表示、公開コミットとURLを残す。
